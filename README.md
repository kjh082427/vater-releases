# Vater 릴리스

**Vater**는 한국투자증권 시세와 AI 분석을 결합한 Windows 설치형 개인 투자 보조 앱입니다.

이 저장소에는 설치 파일과 자동 업데이트 파일(`latest.json`, 서명)만 올라갑니다. **소스 코드는 없습니다.**

## 설치
1. [최신 릴리스](https://github.com/kjh082427/vater-releases/releases/latest)에서 `Vater_<버전>_x64-setup.exe`를 받아 실행합니다. 관리자 권한은 필요 없습니다.
2. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다. 1차 버전은 유료 코드 서명을 하지 않습니다. 업데이트 파일은 별도의 서명으로 검증합니다.
3. 첫 실행 마법사에서 한국투자증권 키를 넣습니다. 키는 [KIS Developers](https://apiportal.koreainvestment.com/)에서 신청합니다.

설치한 뒤에는 앱이 새 버전을 찾아 알려 줍니다.

> 투자 판단 보조용이며 투자 권유가 아닙니다. 앱에는 주문 기능이 없습니다.
